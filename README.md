The workspace contains two folders by default, where:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain dependencies

Meanwhile, the compiled output files will be generated in the `bin` folder by default.

> If you want to customize the folder structure, open `.vscode/settings.json` and update the related settings there.

## Dependency Management

The `JAVA PROJECTS` view allows you to manage your dependencies. More details can be found [here](https://github.com/microsoft/vscode-java-dependency#manage-dependencies).

Common Swing classes include (import javax.swing.*) :
JFrame – creates a window
JPanel – a generic container
JButton – a button
JLabel – a label for text
JTextField – a single-line text input
JTextArea – a multi-line text area
JCheckBox, JRadioButton, JComboBox, etc.



java.awt.event.* — Event Handling
This package provides classes and interfaces for event-driven programming, like handling button clicks or key presses.
Common interfaces and classes:
ActionListener – for handling button click events
MouseListener, KeyListener – for mouse and keyboard interaction
WindowAdapter, WindowEvent – for handling window operations



java.awt.* — Basic GUI Components
This package provides graphical components and layout tools for building GUIs.
Common classes:
Frame – top-level window
Panel – container
Button, Label, TextField, TextArea, etc.
Color, Font, Graphics – for drawing and styling
